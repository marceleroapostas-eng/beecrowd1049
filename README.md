# Beecrowd 1049 - Animal



## Descrição



Este programa resolve o problema 1049 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém três palavras, uma em cada linha, que definem o tipo de animal.



## Saída



O programa apresenta o nome do animal correspondente às três palavras informadas.
